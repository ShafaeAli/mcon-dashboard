(Fine-grained tokens won't work for you — GitHub doesn't let them access a private repo owned by someone else's personal account, which is why the repo never appears in the list.)

Repo owner: a fine-grained token scoped to mcon-firmware-testing with Issues + Contents read-only works too.

The token stays in this browser only (localStorage). Use "Log out" to remove it. When the token expires, GitHub emails you — just make a new one and sign in again.
